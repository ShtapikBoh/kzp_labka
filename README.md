# Розклад занять — консольний звіт

## Призначення

Програма читає записи розкладу занять з `data/input.csv`, перевіряє їх
коректність, обчислює показники та формує звіт у консоль і файл
`out/report.txt`.

Варіант завдання: **№ 3 — Розклад занять**
(курс «Кросплатформні засоби програмування», лабораторна робота № 1).

## Формат вхідних даних

Файл `data/input.csv` — UTF-8, один запис на рядок, поля розділено `;`.

```
subject:String; teacher:String; day:String; room:int; durationMin:int
```

Приклад:

```
Програмування;Олексів М. В.;Понеділок;101;90
Кросплатформні засоби;Рудик Ю. І.;Вівторок;215;120
```

Рядок хибний і пропускається (з номером рядка та причиною), якщо:
- він порожній;
- полів не 5;
- предмет, викладач або день порожні;
- `room` або `durationMin` не є цілим числом;
- `room` або `durationMin` від'ємні.

## Показники звіту

1. Кількість коректних записів
2. Сумарна тривалість (хв і год)
3. Найменший номер аудиторії
4. Найдовше заняття

## Запуск

Потрібен JDK 21.

```
./mvnw verify          # Windows: mvnw.cmd verify
java -jar target/lab01-1.0.0.jar
java -jar target/lab01-1.0.0.jar --input data/input.csv --output out/report.txt
java -jar target/lab01-1.0.0.jar --help
java -jar target/lab01-1.0.0.jar --version
```
