# Звіт до лабораторної роботи № 1

## 1. Тема і варіант

- Предметна область: розклад занять
- Номер варіанта: 3
- Операційна система: Arch Linux

## 2. Мета роботи

Створити відтворювану консольну Java-програму, яку можна зібрати й запустити
на Windows, macOS та Ubuntu: Maven Wrapper, тести, статичний аналіз, jar, CI.

## 3. Постановка задачі

Запис: `subject:String; teacher:String; day:String; room:int; durationMin:int`.
Показники: кількість коректних записів; сумарна тривалість; найменший номер
аудиторії; найдовше заняття. Хибні рядки пропускаються з повідомленням.

## 4. Структура програми

- `src/main/java/ua/lpnu/kzp/Main.java` — розбір аргументів, читання файлу,
  `buildReport`, запис звіту;
- `src/test/java/ua/lpnu/kzp/MainTest.java` — тести JUnit 5;
- `data/input.csv` — приклад даних (3 коректні й 4 хибні рядки);
- `ai/` — файли ролей-агентів.

Потік даних: `input.csv` → розбір і перевірка рядків → накопичення показників
→ текст звіту → консоль і `out/report.txt` (UTF-8, `Path`, формат із `Locale.ROOT`).

## 5. Інфраструктура

Maven (`pom.xml`, groupId `ua.lpnu.kzp`, artifactId `lab01`, версія 1.0.0,
Java 21), Maven Wrapper, JUnit 5.12.2, SpotBugs 4.9.7.0 у фазі `verify`,
maven-shade-plugin для виконуваного jar. GitHub Actions
(`.github/workflows/ci.yml`) запускає `verify` на ubuntu, windows і macos та
публікує jar як артефакт.
